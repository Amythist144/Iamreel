# I AM REEL Investor Website

Static website source and assets for the I AM REEL investor site.

Current live site: https://iamreel-investor.enlightening-6100.chatgpt.site/

## Files

- `index.html`: main scrolling investor website
- `global.html`: Global Vision Project page
- `styles.css`, `global.css`, `script.js`: styling and interactions
- `assets/`: website graphics, photographs, and animated logo

Serve these files as a static website. The current site uses `/global` for the Global Vision Project; configure your host to serve `global.html` at that route.

This repository contains the website files. GitHub Pages has not been enabled.
